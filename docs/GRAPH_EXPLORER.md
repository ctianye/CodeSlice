# 代码与笔记图谱

两套图谱共用 `GraphView`、`GraphCanvas`、社区投影及右侧检查器栏；切换图谱时重新挂载独立状态（上一次载荷由内存缓存即时回放，后台静默刷新）。代码数据来自当前项目的 AST 图谱，笔记数据来自知识库，不将笔记混入代码节点或代码边。界面跟随应用浅色 / 深色主题，画布配色与图例同步切换。

图谱只构建并持久化一次：后端把载荷存进 SQLite（`graphs` 表），读取走一次主键查询，不再遍历源码树；索引任务真正改动文件时才使缓存失效，笔记或目录变更即时失效笔记图谱。

## 交互

- 静态布局：没有自动旋转或持续物理模拟；保留节点拖拽、画布平移、滚轮缩放、点击与悬浮提示。画布占据头部以下除检查器栏外的全部空间，缩放控制按钮位于画布右下角。
- 只有社区中心显示名称，缩小时仅保留度数最高的若干锚点名，放大后逐级恢复。普通节点即使选中也不显示常驻文字；完整名称、类型与来源在 tooltip 和右侧详情中显示。
- 点击社区中心或右侧社区目录可单独收起 / 展开该簇；支持全部收起 / 展开及显示过滤。小图默认展开，超过 120 个节点默认社区总览。
- 搜索覆盖名称、路径和笔记正文。点击结果会解除目标社区 / 类型的隐藏、展开该社区、选中节点并放大聚焦。
- 点击普通节点查看全部直接关系；点击邻点可继续定位。双击打开代码或笔记。
- 点击「AI 总结关系」后在检查器栏显示 Markdown。请求中显示进度并可取消等待；失败可重试。切换节点或图谱会中止旧请求，防止旧结果覆盖当前选择。
- 检查器栏自上而下为：搜索、类型筛选（代码图谱）、社区目录、节点 / 社区详情与 AI 总结、关系图例与统计。窄容器（约 760px 以下）自动切换为画布下方面板，全部控件仍可达。
- 对话栏「定位到代码图谱」先使用持久化的图谱提问锚点，再查片段位置及引用；优先定位覆盖该行的最小代码符号。多个位置可选择，没有明确位置时显示说明，不猜测节点。重复定位会重新展开和聚焦，右侧继续保留原对话。

## 数据及 AI 边界

笔记关系由后端统一构建，画布与 AI 使用相同拓扑。保留原有稀疏链式关系：同目录、同项目未分类、同项目内共同引用代码文件。共同引用边保存文件证据；跨项目的同名文件不会自动关联。

社区节点及成员连线仅为布局索引，不作为 AI 关系证据。总结请求只提交真实节点 ID；后端从对应图谱读取中心节点、全部入向 / 出向直接边和去重邻点。隐藏与收起不缩减总结范围；二跳节点不会进入总结。

总结使用现有 `build_chat_model` 配置的一次无工具模型调用，不新增 LangGraph 节点。提示词要求以中心节点为主、说明方向、区分源码事实 / 推断 / 存疑，不能将笔记同目录或共同引用解释成确定的因果关系。资料超过 180,000 字符时明确拒绝，不静默裁剪邻点；空响应、提供商失败及输出截断会返回错误。

原有 LangGraph 对话入口将 `graph_anchor` 保存到用户消息 metadata。笔记锚点 `note://ID` 读取独立笔记邻域，代码锚点仍走代码图谱。

## API

所有接口均要求 `X-Session-Token`。

| 接口 | 用途 |
| --- | --- |
| `GET /api/projects/{project_id}/graph` | 当前项目代码图谱；命中 SQLite 缓存时 `stats.rebuilt` 为 false |
| `GET /api/graphs/notes` | 独立笔记图谱，沿用 nodes / edges / communities / stats 结构 |
| `POST /api/projects/{project_id}/graph/summary` | 总结代码节点及全部直接邻点 |
| `POST /api/graphs/notes/summary` | 总结笔记节点及全部直接邻点 |
| `GET /api/conversations/{conversation_id}/graph-targets` | 返回所属 project_id 和可定位的代码节点 targets |

总结请求：`{"node_id":"实际节点 ID"}`。响应：`node_id`、`scope`、`summary`、`neighbor_count`、`edge_count`。节点不存在 / 跨图谱 ID 返回 404；未配置模型返回 400；资料超限返回 413；模型失败、空正文或输出截断返回 502。

## 验证

- 后端：在 `backend` 运行 `uv run pytest`。`test_graph_relationships.py` 覆盖完整一跳、252 个邻点、数据隔离、模型错误、鉴权、引用路径和对话定位；`test_graph_cache.py` 覆盖缓存命中、二次读取零源码访问、节点端点不重建、笔记 / 目录变更失效、旧版 `graph.json` 一次性导入与 schema 升级失效；`test_agent.py` 验证持久化锚点与笔记上下文进入模型。
- 前端：在 `frontend` 运行 `npm run test:graph` 和 `npm run build`。纯投影测试验证独立展开、跨社区边置信度、过滤后的边完整性以及笔记复用。
- 浏览器：构建前端后，从 `backend` 运行 `python scripts/graph_preview.py`，打开控制台打印的本地地址。此脚本创建临时样例数据库和本地模拟模型，不读取用户模型凭据。验证静止、悬浮、拖拽、社区切换、总结竞态、两种图谱、重复对话定位、模型错误与空图状态。
- 模拟模型测试验证数据链路和交互；实际生成质量取决于用户配置的模型。

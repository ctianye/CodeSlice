# CodeSlice v0.3.1

本地优先的 AI 代码阅读桌面应用。边读代码边提问，回答带可点击的源码引用；写文件和执行命令始终由你逐条授权。

v0.3.1 合并了社区贡献的四个 PR（#6–#9），并修正长工具轮次下的错误路径与笔记生成体验。

## 安装说明

### Windows

1. 下载并运行 `CodeSlice-0.3.1-Setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」。
3. 安装器默认按当前用户安装，可自行选择目录。

### macOS

1. 下载对应芯片的 `.dmg`：Apple Silicon 选 arm64，Intel 选 x64。
2. 打开 DMG，把 CodeSlice 拖进「应用程序」。
3. 首次启动若被 Gatekeeper 拦截，右键 CodeSlice →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeSlice.app
   ```

4. 应用仅做 ad-hoc 签名、未使用 Developer ID、未公证；系统可能会要求你在「隐私与安全性」里再次确认。

### Linux

AppImage：

```bash
chmod +x CodeSlice-0.3.1-x86_64.AppImage
./CodeSlice-0.3.1-x86_64.AppImage
```

若提示缺少 FUSE，安装 `libfuse2`，或使用解包运行：

```bash
sudo apt install libfuse2
./CodeSlice-0.3.1-x86_64.AppImage --appimage-extract-and-run
```

deb / rpm：

```bash
sudo apt install ./CodeSlice-0.3.1-amd64.deb
sudo dnf install ./CodeSlice-0.3.1-x86_64.rpm
```

arm64 机器请换成对应的 `arm64` / `aarch64` 文件名。

## v0.3.1 更新

- **合并社区贡献**：结构类提问回退到模块概览（#6）；工具密集的长轮次不再丢失回答和提问（#9）；构建脚本补齐可执行位（#8）；修复 Linux 下两个跨平台测试假失败（#7）。
- **轮次耗尽更可靠**：长工具链耗尽轮次时，会基于已读内容做一次不带工具的流式收尾回答；当前提问不会再被挤出历史窗口；「我先看一下目录」这类前言不再被当成最终回答。
- **错误路径修正**：模型服务中途报错时不再把前言当答案，而是明确提示本轮没有生成有效内容；收尾调用沿用 agent 节点配置的模型、温度与输出预算。
- **笔记体验**：笔记页的代码引用条可折叠成一行，展开/收起状态会记住；单条回答生成的笔记只聚焦这条回答及它引用的代码，不再混入整段会话的主题；顶部动作改名为「整理整段对话」。
- **致谢**：感谢 @2215414342 提交的 #6–#9。
- **发布**：版本号统一到 0.3.1，标签为 `v0.3.1`。

升级不会修改你的仓库：版本视图只从 Git 读取内容，不执行 checkout、stash 或 reset，笔记、批注、对话和索引仍保存在本机数据目录。

## 系统要求

- Windows 10（1809+）/ Windows 11。
- macOS 11+（Apple Silicon 或 Intel）。
- Linux x86_64 / arm64，Ubuntu 22.04+ 或 Debian 12+。
- 需要配置兼容的模型服务与自己的 API Key；应用本体、索引和对话数据都保存在本机。

**English:** CodeSlice is a local-first AI code-reading desktop app. v0.3.1 merges the community pull requests (#6–#9): structural questions now fall back to a module overview, long tool-heavy turns keep both the question and the answer, and the packaging scripts and cross-platform tests are fixed. It also corrects the error path so a mid-turn provider failure never ships a preamble as the answer, and improves note generation: the reference bar collapses to one remembered line, and a per-answer note stays focused on that answer and its citations. All packages are unsigned; see the installation sections above for the Gatekeeper/FUSE steps.

# CodeSlice v0.3.2

本地优先的 AI 代码阅读桌面应用。边读代码边提问，回答带可点击的源码引用；写文件和执行命令始终由你逐条授权。

v0.3.2 修复了 v0.3.1 安装后设置页仍显示 0.3.0、更新检查反复提示新版本的问题，并加入发布前的版本一致性校验。

## 安装说明

### Windows

1. 下载并运行 `CodeSlice-0.3.2-Setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」。
3. 安装器默认按当前用户安装，可自行选择目录。

### macOS

1. 下载对应芯片的 `.dmg`：Apple Silicon 选 arm64，Intel 选 x64。
2. 打开 DMG，把 CodeSlice 拖进「应用程序」。
3. 首次启动若被 Gatekeeper 拦截，右键 CodeSlice →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeSlice.app
   ```

4. 应用仅做 ad-hoc 签名、未使用 Developer ID、未公证；系统可能会要求你在「隐私与安全性」里再次确认。

### Linux

AppImage：

```bash
chmod +x CodeSlice-0.3.2-x86_64.AppImage
./CodeSlice-0.3.2-x86_64.AppImage
```

若提示缺少 FUSE，安装 `libfuse2`，或使用解包运行：

```bash
sudo apt install libfuse2
./CodeSlice-0.3.2-x86_64.AppImage --appimage-extract-and-run
```

deb / rpm：

```bash
sudo apt install ./CodeSlice-0.3.2-amd64.deb
sudo dnf install ./CodeSlice-0.3.2-x86_64.rpm
```

arm64 机器请换成对应的 `arm64` / `aarch64` 文件名。

## 校验下载

同时下载 `SHA256SUMS-v0.3.2.txt`，在文件所在目录执行：

```bash

sha256sum -c SHA256SUMS-v0.3.2.txt

# macOS
shasum -a 256 -c SHA256SUMS-v0.3.2.txt
```

## v0.3.2 更新

- **设置页版本显示**：v0.3.1 的安装包版本已生效，但后端 `VERSION` 常量漏改、仍为 0.3.0，导致设置页显示旧版本。本版统一全部版本声明，升级后显示 0.3.2。
- **更新提示误报**：更新检查把 0.3.0 当作当前版本，因此 v0.3.1 发行后持续提示「发现新版本 v0.3.1」。升级到本版后不再误报。
- **防复发**：新增 `scripts/check_version.py`，校验后端常量、`pyproject.toml`、前后端 `package.json` / lock 文件与 `version.json` 一致；`release` 工作流在构建前强制执行，不一致直接失败。
- **打包脚本**：`build_desktop.ps1` 读不到 `package.json` 版本时直接报错，不再静默写入写死的旧版本号。
- **发布**：版本号统一到 0.3.2，标签为 `v0.3.2`。

如果你在 v0.3.1 上看到设置页显示 0.3.0 或持续提示更新，下载本版覆盖安装即可，无需删除应用数据。正常覆盖安装不会修改你的仓库：版本视图只从 Git 读取内容，不执行 checkout、stash 或 reset，笔记、批注、对话和索引仍保存在本机数据目录。

## 系统要求

- Windows 10（1809+）/ Windows 11。
- macOS 11+（Apple Silicon 或 Intel）。
- Linux x86_64 / arm64，Ubuntu 22.04+ 或 Debian 12+。
- 需要配置兼容的模型服务与自己的 API Key；应用本体、索引和对话数据都保存在本机。

**English:** CodeSlice is a local-first AI code-reading desktop app. v0.3.2 fixes a version-reporting bug: the v0.3.1 installer shipped, but the backend still reported 0.3.0, so Settings showed the old version and the update check kept offering the release already installed. All version declarations are now kept in sync by `scripts/check_version.py`, which the release workflow runs before building. All packages are unsigned; see the installation sections above for the Gatekeeper/FUSE steps.

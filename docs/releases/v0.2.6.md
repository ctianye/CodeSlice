# CodeSlice v0.2.6

本地优先的 AI 代码阅读桌面应用。边读代码边提问，回答带可点击的源码引用；写文件和执行命令始终由你逐条授权。

本版修复图谱排布在真正开始前就被判定完成、从而把初始坐标保存成均匀大球的问题。

## 安装说明

### Windows

1. 下载并运行 `CodeSlice-0.2.6-Setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」。
3. 安装器默认按当前用户安装，可自行选择目录。

### macOS

1. 下载对应芯片的 `.dmg`：Apple Silicon 选 arm64，Intel 选 x64。
2. 打开 DMG，把 CodeSlice 拖进「应用程序」。
3. 首次启动若被 Gatekeeper 拦截，右键 CodeSlice →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeSlice.app
   ```

4. 应用仅做 ad-hoc 签名、未使用 Developer ID、未公证；系统可能会要求你在「隐私与安全性」里再次确认。

### Linux

AppImage：

```bash
chmod +x CodeSlice-0.2.6-x86_64.AppImage
./CodeSlice-0.2.6-x86_64.AppImage
```

若提示缺少 FUSE，安装 `libfuse2`，或使用解包运行：

```bash
sudo apt install libfuse2
./CodeSlice-0.2.6-x86_64.AppImage --appimage-extract-and-run
```

deb / rpm：

```bash
sudo apt install ./CodeSlice-0.2.6-amd64.deb
sudo dnf install ./CodeSlice-0.2.6-x86_64.rpm
```

arm64 机器请换成对应的 `arm64` / `aarch64` 文件名。

## v0.2.6 更新

- **修复“排布刚开始就被当成完成”**：vis 的 `stabilize()` 在启动时会先触发一次 `stabilized` 事件，旧代码把它当作完成信号，于是把初始坐标直接存成了最终布局，看起来就是一个均匀的大球。现在只认真正的 `stabilizationIterationsDone`，并忽略空网络提前发出的完成事件。
- **大图完整跑完迭代预算**：`minVelocity` 设为 0，避免速度阈值在几十次迭代后就提前结束；2k+ 节点按 200 次迭代排布，约 10–15 秒一次，之后复用持久化坐标。
- **窗口被遮挡也能完成排布**：启动排布改用 `setTimeout` 而不是 `requestAnimationFrame`，并关闭 Electron 的后台节流，避免窗口在后台时排布永远不开始。
- **只保存真正完成的布局**：看门狗或异常路径不再把初始坐标写进数据库。
- **旧布局一次性失效**：`LAYOUT_VERSION` 升到 3，之前保存成球的坐标会在升级后自动作废并重新排布一次。
- **发布**：版本号统一到 0.2.6。

升级后第一次打开大图会出现“正在排布图谱…”，等待约 10–15 秒；完成后会直接复用布局。

## 系统要求

- Windows 10（1809+）/ Windows 11。
- macOS 11+（Apple Silicon 或 Intel）。
- Linux x86_64 / arm64，Ubuntu 22.04+ 或 Debian 12+。
- 需要配置兼容的模型服务与自己的 API Key；应用本体、索引和对话数据都保存在本机。

**English:** CodeSlice is a local-first AI code-reading desktop app. This release fixes the graph persisting its seed coordinates because vis emits `stabilized` at the start of `stabilize()`: completion now comes only from `stabilizationIterationsDone`, large graphs use their full 200-iteration budget (`minVelocity` 0), the pass starts with `setTimeout` and is not background-throttled, and `LAYOUT_VERSION` 3 retires the old ball-shaped layouts. All packages are unsigned; see the installation sections above for the Gatekeeper/FUSE steps.

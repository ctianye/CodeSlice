# CodeSlice v0.2.3

本地优先的 AI 代码阅读桌面应用。边读代码边提问，回答带可点击的源码引用；写文件和执行命令始终由你逐条授权。

## 下载

| 平台 | 架构 | 安装包 | 说明 |
| --- | --- | --- | --- |
| Windows 10 / 11 | x64 | `CodeSlice-0.2.3-Setup.exe` | NSIS 安装器 |
| macOS 11+ | Apple Silicon（arm64） | `CodeSlice-0.2.3-arm64.dmg` | M1 / M2 / M3 / M4 |
| macOS 10.15+ | Intel（x64） | `CodeSlice-0.2.3-x64.dmg` | Intel Mac |

所有安装包均未使用 Developer ID 代码签名；macOS 包仅做 ad-hoc 签名且未公证。Windows SmartScreen 与 macOS Gatekeeper 会提示来源未知。

## 安装说明

### Windows

1. 下载并运行 `CodeSlice-0.2.3-Setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」。
3. 安装器默认按当前用户安装，可自行选择目录。

### macOS

1. 下载对应芯片的 `.dmg`：Apple Silicon 选 arm64，Intel 选 x64。
2. 打开 DMG，把 CodeSlice 拖进「应用程序」。
3. 首次启动若被 Gatekeeper 拦截，右键 CodeSlice →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeSlice.app
   ```

4. 应用仅做 ad-hoc 签名、未使用 Developer ID、未公证；系统可能会要求你在「隐私与安全性」里再次确认。

### Linux

AppImage：

```bash
chmod +x CodeSlice-0.2.3-x86_64.AppImage
./CodeSlice-0.2.3-x86_64.AppImage
```

若提示缺少 FUSE，安装 `libfuse2`，或使用解包运行：

```bash
sudo apt install libfuse2
./CodeSlice-0.2.3-x86_64.AppImage --appimage-extract-and-run
```

deb / rpm：

```bash
sudo apt install ./CodeSlice-0.2.3-amd64.deb
sudo dnf install ./CodeSlice-0.2.3-x86_64.rpm
```

arm64 机器请换成对应的 `arm64` / `aarch64` 文件名。

## 校验下载

同时下载 `SHA256SUMS-v0.2.3.txt`，在文件所在目录执行：

```bash
# Linux
sha256sum -c SHA256SUMS-v0.2.3.txt

# macOS
shasum -a 256 -c SHA256SUMS-v0.2.3.txt
```

## v0.2.3 更新

- **像 IDE 一样跳转**：`F12` / `Ctrl+Click`（macOS 为 `⌘+Click`）跳转到定义，`Shift+F12` 查看引用，`Alt+←/→` 在跳转历史中前进后退。同名符号会弹出选择器；外部库或未解析位置会说明原因。
- **悬浮信息与同词高亮**：悬停显示符号签名、docstring / `WHY` 注释与相对路径；光标所在符号及全部出现位置带 VS Code 风格方框，按住 Ctrl / ⌘ 时目标词出现下划线。
- **持久化符号索引**：新增 `symbol_defs` / `symbol_refs`，带精确行列与跨文件解析结果，随代码图谱一次建好。
- **普通打开文件不再显示“引用第 1–1 行”**：引用条只在真正带行范围跳转时出现。
- **Linux glibc 兼容修复**：后端改用 uv 管理的 CPython 构建，不再把构建机的 `GLIBC_2.38` 带进 AppImage；构建时审计所有二进制，超过 `GLIBC_2.35` 直接失败。
- **macOS 安装包**：GitHub Actions 在 Intel 与 Apple Silicon runner 上分别构建 DMG。
- **多平台自动发布**：Windows、Linux x64、Linux arm64、macOS x64、macOS arm64 并行构建，统一生成 `SHA256SUMS` 并附加到 Release。

## 系统要求

- Windows 10（1809+）/ Windows 11。
- macOS 11+（Apple Silicon）或 macOS 10.15+（Intel）。
- Linux x86_64 / arm64，Ubuntu 22.04+ 或 Debian 12+。
- 需要配置兼容的模型服务与自己的 API Key；应用本体、索引和对话数据都保存在本机。

# CodeSlice v0.2.5

本地优先的 AI 代码阅读桌面应用。边读代码边提问，回答带可点击的源码引用；写文件和执行命令始终由你逐条授权。

本版修复大型代码图谱重新排布后“坍缩成一个均匀大球”的问题，恢复按社区聚类的布局。

## 安装说明

### Windows

1. 下载并运行 `CodeSlice-0.2.5-Setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」。
3. 安装器默认按当前用户安装，可自行选择目录。

### macOS

1. 下载对应芯片的 `.dmg`：Apple Silicon 选 arm64，Intel 选 x64。
2. 打开 DMG，把 CodeSlice 拖进「应用程序」。
3. 首次启动若被 Gatekeeper 拦截，右键 CodeSlice →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeSlice.app
   ```

4. 应用仅做 ad-hoc 签名、未使用 Developer ID、未公证；系统可能会要求你在「隐私与安全性」里再次确认。

### Linux

AppImage：

```bash
chmod +x CodeSlice-0.2.5-x86_64.AppImage
./CodeSlice-0.2.5-x86_64.AppImage
```

若提示缺少 FUSE，安装 `libfuse2`，或使用解包运行：

```bash
sudo apt install libfuse2
./CodeSlice-0.2.5-x86_64.AppImage --appimage-extract-and-run
```

deb / rpm：

```bash
sudo apt install ./CodeSlice-0.2.5-amd64.deb
sudo dnf install ./CodeSlice-0.2.5-x86_64.rpm
```

arm64 机器请换成对应的 `arm64` / `aarch64` 文件名。

## v0.2.5 更新

- **大图不再坍缩成一个球**：超过 1200 个可见节点时，稳定化迭代从 80 次恢复为 200 次。社区重新分开，UI、检索、存储、测试等区域保持不同的密度和位置，而不是均匀铺成一个圆球。实测 2k+ 节点首次排布约 6 秒，排完后坐标写入 SQLite，再次打开直接复用。
- **中断保护改为“停滞才停”**：监听稳定化进度，连续 15 秒没有进展才结束（硬上限 120 秒）。慢机器不会再在排布进行到一半时被固定成半成品，同时保留原来的防卡死兜底。
- **重新打开不再重复排布**：修复开发模式 StrictMode 重挂载时丢掉已保存坐标的问题；切换标签或重新打开图谱会直接使用已持久化的布局。
- **旧布局一次性失效**：布局 key 加入 `LAYOUT_VERSION`，之前由 80 次迭代生成、看起来是一个球的坐标会自动作废，下次打开重新排布一次。
- **发布**：版本号统一到 0.2.5。

升级后第一次打开大图可能出现“正在排布图谱…”，等待约 6–10 秒即可；之后会直接复用布局。

## 系统要求

- Windows 10（1809+）/ Windows 11。
- macOS 11+（Apple Silicon 或 Intel）。
- Linux x86_64 / arm64，Ubuntu 22.04+ 或 Debian 12+。
- 需要配置兼容的模型服务与自己的 API Key；应用本体、索引和对话数据都保存在本机。
